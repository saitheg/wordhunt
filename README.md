# Word Hunt - Avatar Edition 🌊🦅

A romantic proposal web app themed around Avatar: The Last Airbender, designed as a clone of the "Word Hunt" game. 

## Features
- **Word Hunt Game**: Find the hidden words "BOY" and "FRIEND" in a 4x4 interactive grid using drag and connect mechanics. 
- **Elemental Avatar Theme**: Immerse into the deep Water Tribe blues, Earth Kingdom greens, and Fire Nation accents.
- **Dynamic CSS Animations**: Including waterbending morph animations and background rippling effects.
- **Responsive & Mobile-first**: Built specifically to be experienced perfectly on mobile devices (~390px width). 
- **The Proposal**: Reveals an Aang & Katara scroll asking the ultimate question.
- **Persistent Timer**: Celebrates "Time since we've been together", retaining its start date in `localStorage`. 

## Tech Stack
- React
- Vite
- pnpm
- vanilla CSS modules
- canvas-confetti

## Local Setup

Requirements:
- Node.js
- pnpm

1. **Install dependencies**:
   Run the following command using pnpm:
   ```bash
   pnpm install
   ```

2. **Start the development server**:
   ```bash
   pnpm dev
   ```

3. **View the app**:
   Open `http://localhost:5173` in your browser. (Switch to mobile view or run on your phone for the best experience).
